# LAPIS 粘贴兼容性与验收

## 裁切排查

若粘贴后出现左右文字只显示一半，可按下文检查段落缩进和容器宽度。
wenyan-cli 2.0.11 的内置 LAPIS 主题为列表、标题和行内代码设置了缩进或内边距。
这些是待排查因素，不是已证实的根因。截图文本提取不能证明具体裁切位置；缺少原文章 HTML 和粘贴后的 DOM 时，不要声称根因已确定。

## 默认修复路径

使用 assets/lapis-wechat-safe.css（完整 LAPIS + fixes），在 wenyan 内联 CSS 之前应用。
不能只把 fixes 文件传给 --custom-theme：自定义主题可能替换整套原样式。
保留 LAPIS 蓝色、标题和引用视觉；修复容器盒模型、缩进、换行和代码溢出。
不要用 overflow:hidden 掩盖超宽内容，不要用负边距、固定正文宽度或缩小全篇字号应付裁切。
复制生成页面里的“复制公众号图文”；只复制带内联样式的 #wenyan，不能复制工具栏或预览外壳。
不要全局替换所有 span/code 的 display 或 white-space；代码块与行内代码分别处理。
超过三列的宽表格按实际内容改成分块，不要声称 CSS 能保证所有宽表在手机上可读。

## 两层验收

1. 本地分别在 320、375、414、680px 检查首字、末字、长标题、中英文混排、长链接、行内代码、嵌套列表、引用、表格和代码块；检查水平溢出与祖先 overflow/固定高度，不仅检查滚动条。
2. 在公众号空白测试草稿粘贴同一片段，检查编辑器与手机预览的相同位置。保存前读取已有草稿，避免覆盖正文；未获发布授权时只做本地预览。

第一层通过不能表述为“公众号已验证”。没访问公众号时明确标注“待粘贴后验证”。
已有问题正文需先清空其原有排版或使用空白草稿再粘贴新结果；更新 Skill 不会自动修复已粘贴的内容。

## 回归用例

用 scripts/render-safe.mjs 渲染 assets/compatibility-sample.md；验证 fragment 中没有预览工具栏，文字未丢失，样式已内联。
更换 wenyan 版本后重新读取 LAPIS 上游样式，再合并 fixes，不能盲目沿用旧的完整主题快照。

## 图文复制回归

先内嵌本地正文图片，再生成预览和片段；复制时从当前 #wenyan 序列化，不缓存另一份过期的 HTML。
运行 node scripts/check-images.mjs，检查两张图片的字节、顺序、不同输出目录及两种复制路径。其剪贴板 API 为模拟验证，不等于实际公众号粘贴验收。
历史预览文件包含旧复制代码，安装新版后必须重新生成。
